# Final Application Review

Do this before every submission. The purpose is to catch expensive errors that autofill or an LLM can introduce.

## Identity and logistics

- [ ] Correct company and exact role title.
- [ ] Correct resume version uploaded.
- [ ] Name/email/phone correct.
- [ ] GitHub/LinkedIn/portfolio links correct.
- [ ] Employment dates/titles correct.
- [ ] Education dates/status correct.
- [ ] Location/relocation answer is intentional.
- [ ] Work authorization/sponsorship answer is correct.
- [ ] Compensation answer is intentional.

## Experience truth check

- [ ] Every numeric years-of-experience answer was verified manually.
- [ ] No personal project is represented as professional production experience.
- [ ] No unsupported metric, scale, user count, accuracy, latency, revenue, uptime, or savings claim.
- [ ] Team work is not described as sole ownership unless true.
- [ ] Technologies were not added simply because they appear in the JD.
- [ ] "Production" is used only where supported.

## Writing check

- [ ] First sentence actually answers the question.
- [ ] Response uses the strongest relevant evidence rather than listing skills.
- [ ] At least one detail is genuinely specific to the company/role when appropriate.
- [ ] No canned enthusiasm or generic company praise.
- [ ] No repeated resume paragraphs.
- [ ] Word/character limit respected.
- [ ] Vale/style warnings reviewed rather than blindly auto-fixed.
- [ ] Final response sounds like something Nevyn could explain aloud.

## Submission

- [ ] Attachments open correctly.
- [ ] Optional demographic questions handled intentionally.
- [ ] Final page reviewed before Submit.
- [ ] After submission, update Google Sheet status to Applied and record date/resume version.
